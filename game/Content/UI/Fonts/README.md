# 菜单字体

- 标题：Source Han Serif SC Bold（思源宋体），https://github.com/adobe-fonts/source-han-serif
- 正文与按钮：Source Han Sans SC Medium（思源黑体），https://github.com/adobe-fonts/source-han-sans
- 原版静态 OTF，未裁剪，保留完整简体中文及字体内其他字形。两份 SIL OFL 1.1 许可证随文件保留。
- `TripoMenuStyle.h` 统一字体、行距、标题字距、墨色、分隔线和键帽。
- `DefaultGame.ini` 的 `DirectoriesToAlwaysStageAsUFS` 包含此目录，打包后不依赖玩家系统字体。
- 常用字号：页面标题 32、能力名 38、正文 18、按钮 18、辅助说明 13–16。菜单整体在小视口下等比缩小。
