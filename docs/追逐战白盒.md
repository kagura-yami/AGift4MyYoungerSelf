# 追逐战白盒

## 关卡接入

1. 关卡中放入 `TripoChaseTrigger`，调整 Volume 大小；玩家中心进入范围后启动。
2. 放入一个 TargetPoint，赋给触发器的 `SpawnPoint`。点位是 NPC 胶囊中心，默认离地约 100 cm；需要位于导航区域内，不能嵌在墙内。也可直接移动触发器的 SpawnMarker。
3. 用 `NavMeshBoundsVolume` 覆盖可行走区域，点击触发器详情里的 `Build Navigation For Level` 构建导航（或使用编辑器的导航构建菜单），等待完成后保存地图。NPC 通过导航绕障碍；缺少路径时调试标签显示 `NO PATH`，不会穿墙追赶。
4. 放入 `TripoChaseHideZone`，调整 Volume，玩家中心进入即隐藏。仇恨按 `AggroReductionPerSecond` 衰减，默认 45 点/秒；设为 0 表示立即清零。
5. 需要结束追逐时，蓝图调用触发器 `EndChase`。默认结束本次追逐且不允许立即重触发。

追逐者可创建 `TripoChaser` 蓝图子类，替换白盒外观、调整以下参数，再赋给触发器的 `ChaserClass`。白盒 NPC 头顶显示状态和仇恨；正式关卡可关闭 `bShowDebug`。

## 状态与规则

| 状态 | 行为 |
| --- | --- |
| Chasing | 视野内发现玩家，增加仇恨，定期更新导航目标 |
| Searching | 被遮挡或进入藏身点，前往最后看见的位置并搜索 |
| Wandering | 仇恨归零，在丢失位置附近游荡；重新看见玩家会再次追逐 |
| Caught | 近距离持续接触后判失败，恢复最近有效检查点 |
| Dormant | 尚未开始或已经停止 |

- 普通视野半径 1800 cm、半角 70°；220 cm 内可察觉身后的玩家，但仍受墙遮挡。
- 藏身点内不更新目标位置、不抓取玩家。离开后恢复正常视觉检测。
- 默认初始仇恨 70，最高 100；看见玩家每秒增加 30，普通丢失视野每秒减少 12。
- 默认追逐速度为玩家正常 `MaxWalkSpeed` 的 92%～100%，仇恨越高越快。玩家在空中时额外乘 0.85，搜索/游荡为 55%。速度平滑变化，不复制冲刺瞬时速度，不因玩家停下就停下。
- NPC 目前只在导航地面行走，不会模仿跳跃、瞬移或生成垫脚石。
- 抓取默认要求胶囊边缘距离不超过 12 cm、垂直高度差不超过 88 cm、无墙遮挡，且持续接触 0.15 秒。出生后有 1.2 秒保护期。
- 追逐目标为当前实际操控的角色（包括分身）；轮盘仅预览镜头不改变目标。切换到不可见的身体不会泄露新位置。
- 菜单暂停时停止移动和仇恨变化；读档/检查点恢复后销毁触发器生成的 NPC，默认离开再进入触发点可重试。
- 必须有有效检查点。通常角色出生时自动建立；接入关卡时检查出生点和重生点有稳定地面。`OnPlayerCaught(Player, bRestored)` 可接失败演出；`bRestored=false` 表示恢复失败，不能视作重试成功。
- 单机功能，不提供联机复制。触发器拥有生成的 NPC，关卡卸载时清理。

## 独立测试地图

`/Game/Maps/L_ChaseWhitebox`：穿过起点前方触发区开始，中央墙测试绕路，右后方两个标记区分别测试渐降和瞬间清仇恨。地图生成脚本为 `tools/scripts/create_chase_whitebox.py`，遇到已存在的地图会停止，避免覆盖地编修改。

## 验证结果

- UE 5.7.4 Development Editor 编译通过。
- `Tripothon.Chase` 两项自动化测试通过：移速关系、旋转藏身范围与高度边界。
- 独立地图 PIE 跨帧测试通过 21 项断言，包含实际绕墙运动、两种消仇恨点、游荡、重新发现、暂停、墙体/高度防误抓、抓取恢复、重试和显式结束。
- 复现：打开白盒地图并进入 PIE，通过 `unreal.py --file tools/scripts/validate_chase_pie.py` 启动；只修改 PIE 副本，报告输出 `tools/evaluation/chase-pie.json`。
- 尚未配置住宅或 lv4 的追逐路线；实际场景需要地编放置触发点、藏身点并生成导航。

## Project Context Analysis

### Analysis Purpose
接入追逐与藏身机制，复用角色移动状态、暂停和检查点恢复。
### Codebase Structure
运行时代码在 `game/Source/Tripothon/World`；测试在 `Tests`，地图生成脚本在 `tools/scripts`。
### Dependencies
现有 Engine/Core/GameplayTags 等保持不变；新增私有依赖 AIModule、NavigationSystem。
### Connections
Trigger 创建 Chaser；Chaser 读取当前 Pawn、HideZone 与 RuntimeSubsystem，失败调用 WorldSubsystem.RestorePlayer。
### Architecture Patterns
独立 Actor + 蓝图可配置属性；触发器拥有 NPC，运行时状态不跨关卡保留。
### Codebase Conventions
ATripo 前缀，头源文件配对，反射属性使用 TObjectPtr，运行时观察对象用弱引用。
### Dependency Graph
Trigger → Chaser → Player / HideZone / RuntimeSubsystem / WorldSubsystem；Chaser → AIController / NavigationSystem。
### Component Relationships
Trigger 的 Box 定义进入范围，Arrow 定义默认出生位置；Chaser 使用胶囊碰撞、CharacterMovement 和 AIController；HideZone 的 Box 只定义逻辑范围。
### Key Insights
暂停不一定等于世界停 Tick；恢复通过 Epoch 标识。两者必须显式处理，避免菜单中被抓或重生后继续旧追逐。
