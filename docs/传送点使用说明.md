# 传送点

## 放置

在关卡中放置两个 `ATripoTeleportPoint`（C++ 类名可在 Place Actors 搜索 `Teleport Point`）。给两个点设置相同的 `LinkId`，例如：

```text
入口：LinkId = OfficeExit
出口：LinkId = OfficeExit
```

两个点的 `LinkId` 相同即自动配对；同一组应只放两个点。`TriggerRadius` 控制触发范围，默认 100 cm；`Cooldown` 防止传送后立即反向传送，默认 0.35 秒。箭头方向会作为出口角色朝向。

## 触发规则

- 只有玩家使用水平前向 Dash（前位移）并经过触发范围时才会传送。
- 普通 WASD 移动、跳跃、上冲、墙跳和回溯不会触发。
- 传送会停止当前移动速度，并把玩家放到出口点上方 90 cm。
- 未配置 `LinkId`、找不到配对点、游戏暂停或正在恢复存档时不会传送。

传送点是游戏逻辑 Actor，不依赖最终美术；可在后续替换编辑器显示或添加特效。
