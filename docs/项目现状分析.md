## Dependency Graph

以下为计划关系，不是已存在的代码导入图：

```text
剧情脚本 ──→ 剧情事件 / 章节配置 ──→ 授予、出口与表现
```

## Component Relationships

设计中 Character 持有移动与能力组件；能力驱动登记的时间目标或交互对象；World 范围的 ChallengeSubsystem 管理挑战与重置；GameInstance 范围的 RunSubsystem 保存跨关数据。HUD 订阅状态事件，表现资源不拥有奖励和等级逻辑。
