# 垫脚石滚轮、墙面与破碎

按住 Q 进入预览，滚轮向前推远、向后拉近，松开 Q 放置。滚轮仅在预览中作用。

角色蓝图可配置 StoneMinDistance（默认 120 cm）、StoneMaxDistance（600 cm）、StoneScrollStep（30 cm）；现有 StonePlacementOffset 的 Y/Z 继续控制横向与相对脚底高度。AdjustStoneDistance 可供蓝图调用，输入是滚轮格数。

预览和实际放置共用 CheckPlacement：以整块石头尺寸从角色向目标扫描，遇墙停在近侧，保留小间隙，平台保持水平。最终检查完整体积的重叠与禁建区域。没有碰撞的纯装饰模型不会阻挡扫描。

到期或调用 Shatter 时立即禁用平台碰撞并释放名额，九块无碰撞碎片散开、旋转、下落，末段缩小，0.65 秒后销毁。碎片由石头 Actor 持有，使用行动时钟，随暂停冻结，不启用物理模拟。IsUsable 可供蓝图查询；破碎幂等，不重复生成碎片。读档/清理直接销毁临时 Actor，不额外产生破碎残留。仅实现单机表现。

验证：UE 5.7.4 编译通过，14 项 Automation 通过；新增 Tripothon.Stone.DistanceWallAndShatter 检查距离边界、薄墙近侧放置、不穿墙、解除碰撞、九块碎片及重复破碎。
PIE 验证：调用调距接口后三格从 160 cm 变为 250 cm，成功放置；破碎时九块碎片可见，HUD 名额立即恢复，1 秒后临时石头 Actor 数量为 0。截图 tools/evaluation/stone-fragments00000.png。滚轮绑定已编译；本轮未做实体鼠标滚轮输入测试。

楼梯修正：扫描体起点由脚底改为躯干高度，再扫向脚底相对目标，避免 1.5 米宽扫描体在起点就与相邻较高台阶重叠。仍检查完整路径和最终体积，不忽略楼梯或墙。回归场景新增脚后方较高台阶，要求前方空落点可用，同时保留薄墙不穿透测试。
