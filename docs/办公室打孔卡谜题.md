# 办公室打孔卡谜题

关卡：`/Game/Maps/lv4`。

## 玩家操作

1. 靠近办公室画板，对准画板点击鼠标左键（也支持原有交互键），获得打孔卡。卡片进入现有背包，世界中的卡片消失，不能重复领取。
2. 与书本交互。持有卡片时自动盖在书页上，按住鼠标左键进行二维拖动；可以取下、重新放上。
3. 点击左侧页码翻页。翻页、收起再打开书本都保留当前卡片偏移；拖动有边界，避免把卡片丢到界面外。
4. 在保险箱输入四位密码，点击“确认密码 · 前往目的地”。正确密码直接传送，不再需要领取抽屉里的章节礼物。密码逻辑仍来自原书页：第 3 页左上、第 7 页左下、第 5 页右上、第 1 页右下，目前为 **6249**。

## 调整传送位置

- 蓝图资源：`/Game/Blueprint/Lv4/BP_CipherArrival`，父类 TargetPoint。
- 关卡实例：`LV4_CipherArrival`，位于 `Gameplay/OfficeCipher` 文件夹。
- 当前位置为第三层西装男对面 `(0, 500, 1085)`，与 NPC 水平距离 3 米。移动该蓝图实例就能更改落点，旋转它的 Z 轴可改变玩家到达后的朝向。
- 蓝图原点表示玩家胶囊体中心，放置时需比地面高约 90–100 厘米，四周留出角色空间。
- `LV4_OfficeCipher` 的 `Cipher > Teleport > Code Destination` 引用了该实例。也可复制蓝图实例，再把此引用改为新实例。
- 目的地未配置或被障碍物阻挡时显示提示，不传送、不解锁。正确传送会停止位移技能和移动速度，并尝试更新当前关卡检查点。密码可重复使用。

## 验证

Editor Development 编译通过；PIE 中验证了画板交互领取、打开书本自动盖卡、真实鼠标拖动、真实鼠标翻页后偏移不变、错误密码不传送、正确密码传送、缺失/阻挡落点拒绝传送、重复正确密码传送及拖动边界限制。

配置脚本：`tools/scripts/setup_office_cipher.py`。结果：`tools/evaluation/office-cipher/validation.json`。运行脚本前需打开 lv4 并退出 PIE；脚本会备份地图，保留已有落点的移动位置。

### 2026-10-06 交互遮挡修复

用户复现：正常瞄准画板不能选中，保险箱未弹出密码框。最早失败发生在瞄准/可达性射线：画板的简单碰撞凸包挡在薄交互盒前；保险箱把手及柜体是独立 Actor，挡住原本仅覆盖抽屉的交互盒。此前直接调用谜题方法、复杂射线的测试未覆盖这一路径。

画板组件改为 Custom 碰撞预设，仅忽略 Visibility 通道，保留角色与相机碰撞；点击盒覆盖实际白板面。保险箱点击盒覆盖柜体和把手，避免被独立装饰模型拦截。PIE 实际鼠标左键已领取画板卡片，正常 E 键已打开四位密码输入框；运行时也确认画板 Visibility 响应保持 Ignore。
