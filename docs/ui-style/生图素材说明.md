# 生图版素材说明 · 2026-09-29

当前 index.html 为第二版，第一版保留在 v1.html。
使用内置 imagegen，未使用外部付费 API CLI。

## 素材
- skill-book-generated.png：完整无字手册底图与二段跳概念插画。
- skill-icons-generated.png：4×2 八技能徽章图集，CSS background-position 定位显示，不改写原图。
- generated-preview.png：浏览器实际渲染结果。
- generated-stone-preview.png：切换垫脚石后的检查截图。

生成方向：以 scene.png 的低多边形办公场景为材质与颜色参考；森林绿厚纸册、暖象牙纸页、装订环、橙色书签、低多边形二段跳纸艺场景；无烘焙文字，左侧留八项目录、下方留参数区域。
图标生成方向：统一立体珐琅/纸艺徽章，4列2行，依次为冲刺靴、二段跳靴、蹬墙跳、石台、减慢沙漏、回溯钟、分身、加时时钟。

文字、等级、数据、选中态由 HTML/CSS 渲染。八项可切换；目前只有二段跳专属场景插画，其余用对应大徽章展示。角色是生成的风格示意，未声称复现现有角色模型。数据为演示，不写存档。收起手册按钮仅展示反馈，未连接游戏。
当前是视觉样稿，非已导入 UE 的 UMG 素材包。整图面板在正式接入前应拆分为九宫格背景、独立图标与插画，避免不同宽高比拉伸。窄于800px的评审窗口使用可横向滚动的950px画板，建议展开浏览器看全貌。
