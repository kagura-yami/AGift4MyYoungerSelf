## 技术路线

沿用现有 Slate，不引入网页运行时，不重写存档、剧情、技能或奖励规则。所有类型保留在 Tripothon 模块；已存在 Slate / SlateCore 私有依赖，第一批无需增加模块。现有 ATripoHUD 类路径保持不变，避免影响地图和蓝图。

建议依赖：ATripoHUD → UI 页面/只读展示数据 → Abilities、Progress、Story、World；底层玩法不依赖具体页面。

| 责任 | 位置/所有者 | 生命周期 |
|---|---|---|
| 页面路由、输入模式、暂停原因 | ATripoHUD | BeginPlay 建立，EndPlay 移除根控件并释放资源 |
| 配色、笔刷、纹理引用 | ATripoHUD 中纹理强引用及 Slate 笔刷 | HUD 持有；纹理需 UObject 强引用，笔刷不能指向栈对象 |
| 技能栏和各页面 | Lab/TripoGameUI.cpp | 只接收只读快照与操作回调 |
| 技能、冷却和失败 | UTripoAbilityComponent | 使用原有接口与动作时钟 |
| 挑战、奖励、存档 | UTripoProgressSubsystem | 保留原结算事务 |
| 对话及剧情结果 | UTripoStorySubsystem | 继续/跳过走原 CloseEvent 流程 |

## 页面路由

- 游戏 → Esc 暂停 → 设置 → 操作与教程 → 能力手册；逐级返回，最终恢复游戏输入。
- 暂停入口保留继续、保存安全进度、读取、新游戏、退出、收藏、练习；调试能力配置仅维持现有测试条件。
- 暂停素材只有六个按钮位，实际按钮是动态列表。不能删掉原功能来适应图片；正式版需拆出独立按钮和可伸缩底板。
- 升级奖励候选由 GetCandidates 决定，不能固定三项。超时随机索引当前为私有，若要提前展示结果需增加只读访问，不在 UI 重抽。
- 物品获取目前没有统一拾取弹窗接口。需从实际剧情奖励结果触发，读档不能重复弹出；不得仅凭打开收藏页误判为新获得。
- NPC 当前事件提供标题/正文，头像和独立说话人元数据需补充；无头像时使用空框或隐藏，而不是伪造角色。
- 设置中的音量、画质等必须接到真实设置并持久化，不能先显示假开关。教程页可先独立实现。

## 素材路径与工具

原始素材保留在 docs/ui-style。预检：

```powershell
./tools/.venv/Scripts/python.exe tools/scripts/prepare_ui_assets.py
```

导入函数在 UE 编辑器 Python 中调用（从仓库根目录启动客户端）：

```powershell
./tools/.venv/Scripts/python.exe tools/scripts/unreal.py --code "import runpy; api=runpy.run_path('C:/Dev/Projects/UE/Tripothon/tools/scripts/prepare_ui_assets.py'); api['import_assets']()"
```

导入目标 /Game/UI/Prototype/T_UI_*，TextureGroup UI、RGBA8、sRGB。已存在纹理保留像素内容，同时规范 UI 纹理组、压缩与 sRGB 设置。脚本先检查全部来源，再逐个导入和保存；中途失败不保证整批回滚，可重跑补齐。已在 UE 5.7.4 执行，七张纹理导入并保存成功；DefaultGame.ini 显式配置该目录参与烘焙，打包结果尚未验证。

**生产接入门槛**：生图底板有背景、部分状态为合图，不能作为透明切片直接叠场景。预检 alpha_channel 仅代表通道存在，不代表背景透明。需完成透明边缘、切片、九宫格边距、图标 UV 和压缩检查。原始 RGBA8 仅供预览，正式包应核算纹理内存。运行时使用明确资源引用，保证打包收录，不从 docs 读取文件。
