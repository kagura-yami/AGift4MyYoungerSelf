## 视觉主张

把能力做成一册随身带着的回忆记录：温暖、轻巧、几何轮廓清楚。菜单使用暖白纸页，游戏过程使用薄而清楚的深灰绿信息层。

| 用途 | 色值 | 规则 |
|---|---|---|
| 纸页面板 | #F2EEE2 | 菜单和奖励的主底色 |
| 文字 / HUD 底 | #293D39 | 主文字、选中行、深色信息底 |
| 次要文字 | #7B8479 | 非关键注释；正式实现需再次检查对比度 |
| 唯一常规强调色 | #BC623E | 标签、选中下划线、确认反馈 |
| 分隔线 | #D5D7C9 | 细线，避免每块内容都套边框 |

形状：平直纸页、2–4 px 小圆角按键、少量错位纸影；胶带、书签和印章每个面板至多一个视觉重点。拒绝用大面积纹理损害小字清晰度。正式图标采用统一 2 px 线宽、32/48 px 网格、几何剪影；样稿当前使用字符占位图标，中央礼盒是手写 SVG 意象，不是最终美术。

## 三类面板

1. HUD：7 主动技能固定槽位，按键与冷却清楚；被动加时跟随计时器。中央保留角色、落点和目标视线。提示用深色底提升明亮地面上的可读性。
2. 能力手册：左侧完整目录，右侧单项详情。固定显示按键、等级、关键参数和使用条件；八项能力可切换。纸页只在菜单打开时出现。
3. 通关礼物：像收到一份附有印章的礼物清单。选择高亮 + 橙色下划线，最后单独确认。当前仅演示达标任选流程；超时固定随机结果应采用同样视觉但禁用切换，待后续实现。

主菜单可沿用信封封面；暂停菜单沿用半幅纸页；NPC 交换采用左右两个等级列表，中间箭头；错误提示用小幅深色便签，避免弹出大窗口。

## 字体与动效规格（实施建议）

- 中文用清晰无衬线字体；正文在 1080p 游戏画面建议 18–22 px，辅助文字不承担唯一关键信息。样稿为网页 CSS 像素，UE 需重新按 DPI 标定。
- 标题中等字重；数字使用等宽数字。英文仅用于装饰性小标，不承载必须读懂的规则。
- 开面板：160–220 ms 淡入 + 向上 8 px；选中：100–140 ms 底色切换；奖励确认：一次印章落下，约 220 ms。
- 冷却不闪烁，结束仅一次轻提示。减少动态效果模式取消位移与弹跳。
