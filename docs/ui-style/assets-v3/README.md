能力手册沿用上批素材，入口确定为“设置 → 操作与教程”。现有八技能徽章可复用，不重复生成。设置页专用滑条、勾选框和切页控件尚未补齐。

## 检查与限制

已逐张查看：五类素材保持同一配色与材质；暂停页六个按钮、升级页三张候选、HUD 七槽均符合本批布局目标，留白区没有烘焙文字。
生成结果仍有背景（HUD 的透明请求未按要求实现），不能直接宣称为游戏可用的透明切片。本批定位为已补齐的美术原稿。正式接入仍需抠图、独立切片、九宫格边距、目标分辨率/DPI与对比度验证。
纸页装饰、邮票与叶片保持在边缘；可读区域内避免再叠加复杂底纹。HUD 金属边与装饰在最终缩小时应减弱，不应按整张素材表直接覆盖画面。
inspection.json 保存实际尺寸及像素格式；generation-prompts.json 保存完整提示词与参考素材路径，便于后续定向修订。
本批未修改游戏逻辑、旧交互样稿和 UE 资产，也未提交 Git。
