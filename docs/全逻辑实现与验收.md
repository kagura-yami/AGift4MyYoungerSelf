# 全逻辑实现与验收

更新：2026-09-16。范围为 Windows 单机玩法、功能 UI 和可玩的基础形体关卡。最终美术和 Minecraft 原地图资料由团队提供。

## 已接通的游戏流程

新游戏 → 34 个剧情事件 → 分阶段获得八项能力 → 8 个挑战 → 限时自选或超时固定随机奖励 → 纪念物与回信 → 继续驻足、重游或独立练习。

`L_Tutorial` 为连续教学地图；`L_LogicLab` 为独立实验场。练习与故事使用不同存档槽，练习菜单可以解锁全部三级能力。默认启动进入故事主菜单。

## 操作

| 输入 | 行为 |
|---|---|
| WASD / 鼠标 | 视角决定移动方向，身体跟随；保留用户已确认的镜头方案 |
| Space | 跳跃；空中靠近标记墙时蹬墙 |
| Shift / Ctrl | 平面位移 / 上位移；各自消耗空中次数，落地恢复 |
| 按住 Q / 松开 Q | 预览 / 放置垫脚石；要求允许区域、无碰撞、容量未满 |
| F | 减慢视线前方且无遮挡的标记平台 |
| R / T | 自身时回 / 前方标记平台时回 |
| C | 回放冻结的近期历史；再次按下取消分身 |
| E | 剧情、附近开关、邮差交换 |
| Backspace | 重开尚未结算的挑战并重新计时 |
| Esc | 暂停菜单、存读档、纪念物、练习入口 |
| F9 | 仅 LogicLab 的练习位置重置 |

HUD 只显示已经获得的能力。奖励加时为被动能力，起跑时锁定 5/10/15 秒加成。

## 实现位置与配置

| 目录 | 职责 |
|---|---|
| `game/Source/Tripothon/Core` | ActionClock、RunId、恢复阶段、稳定身份、数据验证 |
| `Player` | Enhanced Input、视角主导控制、自定义冲刺与回溯移动 |
| `Abilities` | 八项定义与执行器、三级参数、冷却、失败原因、临时石块 |
| `World` | 踏板、开关、AND/OR 门、移动平台、区域、检查点事务 |
| `Time` | 最多 240 帧 / 7 秒历史、时间戳插值、移动基座相对记录、分身 |
| `Progress` | 挑战、奖励快照、一次结算账本、NPC 交换、双槽存档 |
| `Story` | 前置条件、结果与观看记录分离、剧情触发、无玩法权限的记忆地标 |
| `Lab` | 游戏模式和 Slate 功能 UI |

能力参数可在 `UTripoAbilityDefinition` 覆盖原生默认值；挑战配置位于 `/Game/Data/DA_*`；剧情为 `/Game/Data/DA_Story`。编辑器的 Data Validation 接入三种配置类型。剧情循环依赖、重复事件、非法等级、非法奖池均会被拒绝。

机关的 `Visual` 可替换显示模型，`Body` 保留固定玩法碰撞；角色显示模型不负责胶囊碰撞。不要通过替换 `Body` 来接入美术。模型、材质、声音和动画的最终效果仍需在正式资源导入后核对。

## 时间、恢复与存档规则

- 冷却、挑战钟、临时物寿命使用 ActionClock。菜单暂停停止推进；局部减速不修改全局时间。减速源取最小速率，并按一帧内的开始/到期边界积分。
- 普通死亡恢复检查点，挑战钟继续；主动重开恢复挑战起点并重置挑战钟。两者都按锁定、取消技能、恢复机关、恢复角色、清历史、刷新重叠、解锁的顺序执行。
- 时回通过扫掠移动检查当前碰撞；不回退等级、奖励或冷却。自身时回暂停交互并取消自己的分身。
- 分身只拥有显式允许的踏板/开关权限。剧情、奖励、NPC 和存档只接受主角。记忆投影没有这些权限。
- 存档要求稳定安全地面，未结算挑战不能存。交替写 `TripothonStory_A/B`；独立练习写 `TripothonLab_A/B`。写后读回校验，继续游戏选择兼容且序号最新的有效槽。
- 存档记录地图、安全位置、机关状态、能力等级、挑战账本、剧情结果/观看、交换事务和回信。临时石块、分身、未完成挑战不跨存档恢复。位置失效时保留进度并使用关卡起点。
- 所有恢复候选位置都受阻时保持锁定并提示读档，避免把玩家放入阻挡体；可用 Esc 打开菜单。

## 仍属于外部输入的内容

- 角色、环境、动画、音效、配音和最终 UI 美术。
- Minecraft 原存档、真实地标、昵称、留言与合影；现有三个地标是明确标注的替换位置。
- 正式关卡的空间叙事、美术布局和最终难度定稿；当前交付为连续教学灰盒与实验地图。
- 素材授权、赛事表单和最终发布渠道材料。现有基础形体来自 Unreal Engine，第三方 MCP 仅在编辑器使用，未加入运行时依赖。

不把缺失的原图、美术或未经测量的最终性能写成已完成。
