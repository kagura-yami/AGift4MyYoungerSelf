# 剧情呈现

## 角色对话

气泡底色由左至右线性降低不透明度（80% → 6%），圆角边缘羽化。底图运行时生成并缓存；正文独立绘制，附轻微阴影，不随背景渐隐。

现有剧情统一使用左下角气泡，逐行推进。`DA_Story` 的 Text 每行一句，支持实际换行与 `\n`。格式为 `角色名：台词`；没有角色名的行按旁白显示。统一使用轻薄半透明深色底，角色名以青绿／暖金区分主角和其他角色；去掉重复标题与首字徽标，正文 17 号、宽度 400，普通对话不显示继续／跳过提示，结尾回信保留选项。

对话不阻挡角色移动、跳跃、技能和鼠标视角，也不显示鼠标光标。每句按长度停留 4–12 秒后自动推进，最后一句自动关闭；暂停或奖励面板期间停止计时，回信选择等待玩家输入。Enter 推进一句，最后一句结束事件；Tab 跳过。结尾回信选项在最后一句出现，使用数字 1/2/3 选择。气泡不接收鼠标点击，技能栏位于左上角，对话位于左下角。暂停菜单或奖励面板打开时暂时隐藏对话，关闭后恢复。剧情条件、能力发放和跨关逻辑继续由原剧情系统处理。

## 墙面系统提示

在 `TripoStoryTrigger` 的 `Story | Presentation` 中开启 `bWallNotice`，调整 `WallNotice` 组件的位置、旋转、缩放，使组件正面朝向房间，略离墙面以避免闪烁。内容读取同一触发器绑定事件的标题与正文。使用世界空间组件，受场景遮挡，不跟随镜头。

提示始终可见；玩家满足条件并触发时照常应用剧情奖励及完成标记，但不打开对话窗口。仅用于纯操作提示，不用于有分角色台词或回信选择的事件。

Home 第二版的 `Story.Home.GrantUpward` 已接入墙面提示。其他关卡可按同样方式摆放；混合台词的事件保留对话气泡，未自动搬到墙上。
