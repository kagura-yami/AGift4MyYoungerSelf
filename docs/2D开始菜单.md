# 独立 2D 开始菜单

## 入口

- 关卡：`/Game/Maps/L_MainMenu`。在编辑器中打开该关卡后运行即可测试。
- GameDefaultMap 已设为该关卡；编辑器直接运行 lv4 等关卡仍跳过开始菜单，方便测试。
- `TripoFrontEndMode` 不生成玩家角色。Slate 全屏不透明背景遮盖视口，菜单不依赖 3D 场景、灯光或相机。

## 页面与流程

- 继续旅程：沿用 Story A/B 安全存档选择逻辑；没有存档时禁用，有损坏或不兼容存档时显示中文提示。
- 新的旅程：进入配置的第一关 HomeVertical_02。不会在确认页面删除旧存档。
- 设置与教程：接入现有操作指南、能力手册。此批未新增音量、画质或键位重绑设置。
- 暂停及其子页使用不透明 2D 背景；更多选项提供返回开始菜单，按钮文字提示未保存进度会丢失。
- 沿用思源字体与已有透明纸张素材；小视口等比缩小，宽屏余量由全屏底色填充。

## 验证

UE 5.7.4 编译；PIE 检查菜单无 Pawn、设置和返回、新游戏进入 lv4、返回独立菜单。视觉截图位于 `tools/evaluation/frontend-*.png`。

实现：`TripoFrontEnd.cpp`、`TripoSlateHUD.cpp`、`TripoGameUI.cpp`；地图生成脚本：`tools/scripts/create_frontend_map.py`。

## 生图主视觉重制

- 全屏背景：`/Game/UI/FrontEnd/T_MainMenuDesk`，生图源文件保留在 `tools/art/frontend/main-menu-desk.png`。
- 暖光书桌、雨窗与礼物作为标题画面；移除右侧说明卡和大矩形按钮。
- 中文标题、选项均实时绘制；选项使用黄铜色菱形、悬停色和轻微背景反馈，进入页面淡入。
- `import_frontend_art.py` 将原图导入为 UI 纹理；独立 2D 菜单和原有存档流程保持不变。

## 主菜单按钮动效
- 悬停与键盘聚焦：平滑右移 6px，黄铜色渐亮，底部细线展开。
- 按下：缩小 1.8%、下沉 2px；松开后播放 0.16 秒暖金亮起反馈再执行操作。
- 同组按钮触发期间拦截重复请求，禁用按钮不播放悬停反馈。
- UE 5.7.4 编译通过；PIE 实际鼠标点击验证新游戏确认及取消返回。

## 正式关卡顺序

- 第一关：HomeVertical（住宅）。
- 第二关：School（学校）。
- 第三关：lv4（地图资源名保留 lv4，游戏关卡顺序为第三关）。
- HomeVertical 目录包含 L_Home_Vertical_01、L_Home_Vertical_02；School 包含 School、School_v2，本次默认使用 HomeVertical_02 和 School_v2，可在 DefaultGame.ini 的 TripoProgressSubsystem 配置中更换。

## 正式流程接入

- 地图顺序在 `DefaultGame.ini` 配置：HomeVertical_02 → School_v2 → lv4。
- 新游戏创建全新运行状态，从第一关 PlayerStart 出发；不会自动加载或删除旧存档。
- 首次安装不附带 Saved/SaveGames；继续旅程只对校验通过且地图存在的存档可用。
- 第一、二关的终点礼物处新增 E 交互出口，保留 DA_Story 中原有剧情与挑战前置条件。
- 住宅出口只在第一关跳转，学校内原有住宅剧情不会导致循环加载学校。
- 跨关保存原关卡安全进度并携带技能等级；保存失败时保留对话以便重试。
- `tools/scripts/setup_chapter_flow.py` 可重复执行；修改地图前备份到 tools/evaluation/chapter-flow-backup。

验证：UE 5.7.4 编译通过；Tripothon.Flow.ChapterPackages 自动化通过。PIE 验证无存档检测、新游戏进入住宅、原始出口前置条件拒绝、受控出口剧情跨关到学校、技能等级保留及学校不循环跳转。未人工跑完两关路线；School_v2 现有部分模型依赖缺失仍需补齐。测试存档已隔离，原存档已恢复。
