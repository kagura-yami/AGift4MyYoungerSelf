# 技能调整（2026-09-26）

默认参数（自定义 AbilityDefinition 仍优先）：

| 技能 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 平面位移距离 cm | 242 | 418 | 715 |
| 上位移速度 cm/s | 440 | 660 | 990 |
| 蹬墙跳强度 cm/s | 420 | 580 | 750 |

2026-09-29 核对：表中上位移数值为基础强度。当前二段跳保留水平速度，直接进入重力运动，不再匀速上冲。初始竖直速度为 sqrt(UpDashHeightScale × (Strength² + 2 × g × Duration × Strength))，高度缩放默认 0.715，Duration=0.2 仅参与高度换算，冷却 2 秒。详见[当前技能与 UI 设计基线](./当前技能与UI设计基线.md)。

普通跳跃 `JumpHorizontalSpeedScale` 从 1.1 改为 0.66：水平起跳速度和普通跳跃期间的空中速度上限均为上一版的 60%（594 → 356.4 cm/s），在相同满速起跳、无阻挡及同高度落地条件下，水平距离减少 40%。落地恢复地面速度；竖直起跳速度不变。

旧字段 `UpDashHorizontalDistance` 仍保留，但当前二段跳路径不再读取；原先“0.2 秒额外移动 31.2 cm”的行为已被连续水平动量替代，不能作为当前参数使用。

## 垫脚石

角色蓝图属性 `StonePlacementOffset` 默认 `(160, 0, 16)`，以角色脚底为原点，X 为水平视角前方、Y 为右方、Z 向上（厘米）。不受抬头低头影响。按住 Q 显示实际落点的线框虚影，松开 Q 放置；编辑器中的绿色/红色轮廓表示可放/不可放，HUD 同时提供提示。预览与放置共用判定。

没有 BuildAllowed 区域的地图默认允许放置；有此区域的地图要求石块全部落在允许区。BuildForbidden、实体碰撞、数量上限仍生效。默认石块底面高于脚底 3.5 cm，不再埋入同高度地面。垫脚石位置改由 StonePlacementOffset 控制，旧参数 Distance 不再决定落点。

## lv4 特殊位移

放置两个 TripoTeleportPoint，使用相同 LinkId（同组严格两个点）。在入口勾选蓝图可写属性 `Ignore Collision In Lv4`，角色在入口范围内使用平面位移，即传送到配对点；仅 lv4 开启无碰撞落点检测。其他地图仍进行碰撞检查。

出口 `DestinationOffset` 默认 `(0,0,90)`，可由蓝图调整。无碰撞模式允许穿越阻挡和占用的落点，关卡需把出口放在可活动位置。成功传送后结束本次冲刺并清零速度，保持原视角与朝向。普通移动、上位移不触发。
